# Reader guide: what the library chat does

Open the library in a browser (http://localhost:8000 on the library computer).

## Asking

* Type or speak a question in any Indian language or English, and press **Enter** (or the arrow
  button). **Shift+Enter** starts a new line.
* The answer comes **from the books in the library**: it cites the passages it uses, like [1],
  and lists them under **References** with the book, page and line (or verse) so you can look them up.
  A green *Checked against the books* badge means every quoted sentence was found in the cited passage.
* If the books do not contain the answer you see *Not found in the books*, with the closest passages
  found. The question goes to the library admin, who can add an answer.
* Spelling mistakes are corrected using words that appear in the books; the answer says what was searched.
* Ask about the library itself: *"which books are in the library"*, *"summary of each book"*,
  *"summary of Vachanamrut"*.

## Choosing books

**All books** (below the question box) opens the **Library**: tick books to search only those. With
nothing ticked every book is searched. A question that mentions "all books" or "the library"
searches the whole library and says so.

## Language

**Auto** answers in the language of the question; choose a language to always answer in it. The menu
also switches the screen language (English, ગુજરાતી, हिन्दी).

## Under each answer

| Button | What it does |
|---|---|
| **Read aloud** | reads the answer with a **male voice** (never a female voice) |
| **Copy** | copies the answer |
| **Translate** | translates the answer into another language, shown below the answer |
| **Helpful / Not helpful** | rates the answer; *Not helpful* lets you write what the answer should have been (the admin reviews it) |

Each reference can be opened to read the passage, read it aloud, translate it, copy its reference, or
**Show surrounding text** with line numbers.

## Translation

* The first time you translate, the **terms** appear: translations are made by AI and can contain
  mistakes; the original book is the authority. Tick *I understand* and accept. If the admin changes the
  terms you are asked again.
* Translations are labelled **AI translation**. If one is wrong, **Suggest a better translation**
  sends your correction to the admin, who can approve it so it is used from then on.
* While a translation runs, the question box and *Read aloud* are paused; **Stop** (the square button)
  cancels it.

## Voice

* **Microphone** button (or **Alt+M**): speak your question. In browsers without voice input (Firefox)
  the computer's own speech recognition is used if installed; otherwise type.
* **Hands-free** (top right, or **Alt+V**): speak, hear the answer, speak again. It keeps listening through
  short silences, carries on after an answer that failed, and listening starts again when you press **Stop**
  while an answer is read. Say **"stop"** (or बंद / બંધ) to end it; after about a minute of silence it pauses
  by itself. Some browsers (Safari) need a tap on the microphone to listen again after the screen locks.
* **Stop** (square button, or **Alt+S**) stops reading aloud. **Alt+R** reads the last answer again.
* Settings: speaking speed, read answers automatically, also read source names.
* On phones and tablets sound plays only after a tap: tap **Read aloud**.

## Downloads

Books the admin allows show **Download PDF** in the Library. The PDF has a cover page with the
library's signature and a copy code on every page. Published translations show
*"<language> translation (AI), PDF"*; the terms are shown first and printed on its cover.

## Chats

Chats are listed on the left (on phones: the sidebar button at the top left), grouped by day. Each can
be renamed, downloaded or deleted. **New chat** starts a fresh one.

## Display and accessibility

* Settings: light, dark or high-contrast theme; text size.
* Everything works with the keyboard and with screen readers (VoiceOver, NVDA, TalkBack): labelled
  buttons, a skip link, and spoken announcements of answers and status.
* Keyboard shortcuts: **Alt+M** microphone, **Alt+S** stop, **Alt+R** read again, **Alt+V** hands-free,
  **Alt+N** new chat, **Alt+/** question box. The **Keyboard shortcuts** item lists them.
